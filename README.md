# SBT ITB

**✅ Українська** | [☑️ English](./README.en.md)

Тут зібрані наші допоміжні інструменти для роботи з ресурсами гри Into the Breach.

## Список команд

Головний виконуваний файл `sbt-itb` є CLI-програмою з низкою підкоманд, перелічених нижче.

### Робота з ресурсами

Основні ресурси гри, такі як шрифти та зображення, запаковані у файл `resource.dat`.

- `dat list` — перегляд ресурсів. Підтримує вивід у JSONL (з прапорцем `--json`), що чудово поєднується з Nushell або `jq`.
- `dat extract` — видобування ресурсів на диск.
- `dat pack` — створення нового `dat`-файлу з теки на диску.
- `dat patch` — оновлення окремих файлів у наявному `dat`-файлі: заміняє файли, що вже існують в архіві, або додає нові.

#### `sbt-itb-mini`

Окрім того є змога зібрати окремий виконуваний файл `sbt-itb-mini`, що фактично являє собою врізану версію `sbt-itb dat patch` зі вшитими значеннями для вхідних параметрів залежно від операційної системи. Ми поставляємо саме цю версію інструменту з нашим українізатором, щоб патчити ресурси гри.

Зібрати можна через
```
go build ./mini
```

### Робота з CSV

Переклади містяться в CSV-файлах, і ми розробили для цього окрему команду `csv merge`, та врешті вона не стала в пригоді, хоча досі присутня в програмі.
